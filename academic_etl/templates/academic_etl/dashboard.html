Command cookbook

CLI workflow
StepCommandPurpose
Discover python manage.py discover_country_institutions --country "India" --limit 100 Create seeds from Hipo Labs and classify them.
Crawl python manage.py crawl_country --country "India" --limit 20 Fetch official pages and extract staged records.
CSV seed python manage.py seed_from_csv --csv "sample_data/University_Import_Clean-7.csv" --country "India" Load curated CSV rows directly into staging.
Validate python manage.py validate_country_run --run-id <id> Score completeness, confidence and data issues.
Dry-run import python manage.py import_country_run --run-id <id> --approved-only --dry-run Preview create/update/skip decisions before live import.
Fanar build python manage.py build_country_fanar --country "India" --max 200 --with-majors Wikipedia roster + Fanar API enrichment (50 req/min). Includes specializations.
Setup countries python manage.py setup_country_configs Bootstrap country configs (currency, denominations, degree mapping) for 30+ countries.
Schedule crawl python manage.py schedule_crawls --country "Vietnam" --frequency monthly Set up recurring crawl automation for a country.
Refresh rates python manage.py refresh_exchange_rates Fetch latest currency exchange rates for financial format standardization.
